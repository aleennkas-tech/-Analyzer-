# محلل السيرة الذاتية الذكي | AI CV Analyzer

تطبيق تفاعلي باللغة العربية مبني باستخدام **Python** و **Streamlit** لتحليل التشابه النصي بين السيرة الذاتية والوصف الوظيفي. يستخدم **TF-IDF** و **Cosine Similarity** ويعرض المهارات المشتركة والمهارات المطلوبة غير المذكورة في السيرة وفق قاموس مهارات محدود.

## المزايا
- إدخال نص السيرة الذاتية أو رفع ملف PDF / DOCX / TXT.
- إدخال وصف الوظيفة وتحليل التشابه النصي.
- عرض المهارات المشتركة والمهارات غير المذكورة في السيرة.
- توصيات عامة لتحسين عرض الخبرات.

## التشغيل محليًا
يُفضّل Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
streamlit run app.py
```

ثم افتحي العنوان المحلي الذي يظهر في الطرفية، عادة `http://localhost:8501`.

## الخصوصية والحدود
- لا يتضمن الكود تخزينًا دائمًا للسير الذاتية أو إرسالها إلى خدمة تحليل خارجية. إذا نُشر التطبيق على خادم، فقد تُعالج الملفات في بيئة الاستضافة؛ راجعي سياسة الخصوصية قبل رفع أي بيانات حقيقية.
- النتيجة **تشابه نصي** وليست احتمالية قبول وظيفي، ولا تُستخدم لاتخاذ قرارات توظيف آلية.
- لا يدعم قراءة ملفات PDF المصوّرة دون OCR.
- استخراج المهارات قائم على قائمة محددة ومطابقة كلمات، وقد لا يتعرف على المرادفات والمهارات الضمنية.
- لا توجد بيانات تدريب أو نسبة دقة مُقاسة لنموذج تصنيف؛ تُحسب درجة التشابه من النصين مباشرة.

## تجربة سريعة
1. شغّلي التطبيق.
2. الصقي نص سيرة ذاتية تجريبية.
3. الصقي وصف وظيفة.
4. اضغطي «تحليل السيرة الذاتية» لعرض النتيجة.
